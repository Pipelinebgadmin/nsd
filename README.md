# NStock

Inventory, blending, and formula management web app (Flask).

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000. On first run you'll be sent to `/setup` to create the admin account.

## Deploy to Render

1. Push this repo to GitHub.
2. In Render: **New → Blueprint**, pick the repo. Render reads `render.yaml` and creates the web service with a 1 GB persistent disk.
3. As soon as the deploy finishes, open the site and create your admin account at `/setup` (the first person to visit it becomes admin).

### Environment variables

| Variable | Purpose |
|---|---|
| `FLASK_SECRET_KEY` | Signs login sessions. Auto-generated by the blueprint. |
| `NSTOCK_DATA_DIR` | Where data is stored. Set to `/var/data` (the persistent disk). |
| `NSTOCK_HTTPS` | `1` = secure cookies (Render serves HTTPS). |
| `LEDGER_PASSWORD` | Optional fallback ledger password. |
| `PYTHON_VERSION` | `3.12.6` |

### Important: data storage

All data lives in JSON files inside `NSTOCK_DATA_DIR`. Render's normal filesystem is wiped on every deploy, so the persistent disk is required (paid plan). Keep `--workers 1` in the start command; the app writes JSON files and more than one worker process could overwrite each other's changes.

To move existing data from your computer, copy the contents of your local `data/` folder into `/var/data` using the Render Shell or `scp` (see Render docs on disks).

The `data/` folder is in `.gitignore` on purpose; it holds users, password hashes, and the secret key. Never commit it.
